# 安全模型

## 密钥

生产环境必须使用随机且互不相同的会话密钥、管理员令牌、监控令牌和 `FORPAY_ENCRYPTION_KEY`。`.env` 权限应为 `600`，密钥不得写入前端、日志、二维码、备份说明或公开工单。

## 支付安全

- 订单使用高熵 token 和短有效期。
- 二维码文件不通过公开静态目录暴露。
- 二维码接口需要订单 checkout Cookie，并禁止缓存。
- 展示金额按通道并发锁定，到账通知必须匹配通道、金额、有效期和唯一编号。
- 未匹配通知只能人工复核，人工补单写入审计事件。

## 网络安全

回调地址会进行协议校验、DNS 解析和私有地址拒绝，重定向被关闭。生产环境仍应在 Nginx、主机防火墙或云网络层设置 DNS 级 SSRF 出口策略。内置 WAF 只是基础过滤器，不能替代专业 WAF。

## 部署安全

PostgreSQL、Redis 和 Uvicorn 不应暴露公网；CORS 不能使用 `*`；`/metrics` 只能允许内网 Prometheus 抓取；数据库、`data/` 和密钥必须定期备份并验证恢复。
